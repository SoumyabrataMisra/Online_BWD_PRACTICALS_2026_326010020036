A college website made for learning

This is a student project made using basic information about Marwadi University.

About the College

Learning is not only in the classroom

Marwadi University is in Rajkot, Gujarat. The university has different courses and study programmes for students.

I used this information to make a simple website where students can easily find college and course details.

Project Note

This website is only my educational project. It is not the official Marwadi University website.

Vision

Students and Learning

Students should get knowledge, practical skills and confidence to work with others.

Mission

Learning and Skills

The aim is to connect classroom learning with projects, technology and useful skills.

How I Made This Project

01 · Structure

First I created the HTML pages and common navigation.

02 · Design

Then I added CSS for colours, cards, spacing and hover effects.

03 · Framework

I used Bootstrap for the navbar, grid, buttons, forms and responsive design.

04 · Interaction

Finally I added JavaScript for the form, navigation and small page interactions.
