# Marwadi University - HTML5 Geolocation Project

## Project Title
College Information Webpage with HTML5 Geolocation and Iframe Map

## Project Description
This project creates a college information webpage for Marwadi University.
It presents basic university information, selected academic programs,
the university address and contact details, an interactive Google Maps
iframe, and an HTML5 Geolocation feature.

The Geolocation API allows the browser to request the user's current
latitude and longitude. The iframe embeds Google Maps so that the
university location can be displayed without building a map application
from scratch.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- HTML5 Geolocation API
- Google Maps iframe

## Files
- `index.html` - Main webpage
- `style.css` - Page styling
- `script.js` - Geolocation JavaScript
- `README.md` - Project documentation

## How to Run
1. Open the folder in Visual Studio Code.
2. Open `index.html` in a browser.
3. Click **Get My Current Location**.
4. Allow location permission when the browser asks.
5. The latitude and longitude will be displayed.

For best Geolocation results, run the project using VS Code Live Server
or another local HTTPS/secure environment. Modern browsers restrict
Geolocation on insecure pages in many situations.

## Iframe Explanation
An iframe (Inline Frame) embeds external content inside the current
webpage. This project uses an iframe to display the Google Maps location
of Marwadi University. This avoids developing a complete mapping system
inside the project.
