TECHFEST 2026 - COLLEGE EVENT WEBSITE
==========================================

Created for:
Marwadi University

Files:
- index.html       Main webpage
- style.css        Styling and responsive layout
- assets/          Event media files

HOW TO USE:
1. Open the folder in Visual Studio Code.
2. Open index.html in a web browser.
3. The event photograph is already included as an SVG placeholder.
4. Replace:
   assets/promotional-audio.mp3
   assets/event-video.mp4
   with your own MP3 and MP4 files.
5. Keep the filenames the same, or update the filenames in index.html.

FEATURES:
- Responsive navigation
- Hero section
- Event photograph
- HTML5 promotional audio player with controls
- HTML5 event video player with controls
- Event details section
- Responsive design for mobile and desktop
- Clean modern college-event layout
